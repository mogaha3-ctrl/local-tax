# 실제 사용한 프롬프트

이 프로젝트의 프롬프트는 두 층입니다.

1. **프로젝트 지시문** — [`CLAUDE.md`](../CLAUDE.md). AI 코딩 도구(Claude Code)가 작업을 시작할 때마다 먼저 읽는 문서입니다. 목표, 구조 원칙(판정은 `js/engine.js`, 기준값은 `data/rules.js`에만), 화면 원칙(쉬운 한국어, 색과 모양 병행), 보안 금지사항, 매뉴얼 핵심 기준을 담았습니다.
2. **한국어 요청** — 그 위에서 담당자가 말로 한 요청입니다. 아래는 원문 그대로 옮긴 예시입니다.

| 작업 | 요청 원문 |
|---|---|
| 발표영상 | 이런 방식으로 지방세 오류 조기 알림 서비스 프로그램에 대해 발표자료를 직접 설명하는 5분이내로 만들어주는데, 다음의 채점기준(4가지/100점)에 맞게 멋지게 만들어줘. 1. (문제 인식: 40점) … 2. (기능 구현 수준 : 30점) … 3. (완성도 : 20점) … 4. (확산 가능성 : 10점) … |
| 캐릭터 목소리 | 평상시 캐릭터의 목소리를 만들어줘 |
| 발음 보정 | 골든타임! 제가 막습니다에서 막습니다 조금만 더 발음을 뚜렷하게 해줘. 장애상황에서 비상을 조금더 위급하게 말해주고 뚜렷하게 말해줘. |
| 화면 개선 반영 | 대시보드도 모두 다 알기쉽게 바꾸었다는 내용도 추가해줘 |
| 캐릭터 7종 | 골키퍼 캐릭터도 하나만 쓰지말고 상황별 7종이 다 나오게 영상 만들어줘 |
| 배포 오류 | 발표영상에도 두 가지 넣어주고, 이 오류도 확인해서 해결해줘 |

> Build Camp 개발 단계(판정 엔진·장애 접수 화면) 요청 원문은 당시 대화 기록에서 골라 추가할 예정입니다.

## AI 결과를 그대로 믿지 않는 장치

- 판정 로직을 바꾸면 `tools/test.js`에 사례를 추가하고 `node tools/test.js`가 통과해야 한다는 규칙을 지시문에 넣었습니다(현재 48개 통과).
- 기준값은 `data/rules.js` 한 곳에만 있어, 담당자가 매뉴얼과 직접 대조할 수 있습니다.
- 원문 확인이 안 된 값은 화면과 README에 '확인 필요'로 표시합니다.
